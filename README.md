## 仓库结构

```text
Agent_Course/
├── README.md                 # 完整资源索引
├── OVERVIEW.md               # 整体评价与选择
├── courses/<course-id>/      # 每门课程的个人学习空间
│   ├── README.md             # 官网、内容地图和研究入口
│   ├── notes/                # 章节笔记
│   ├── practice/             # 环境、Demo、成功与失败记录
│   └── review.md             # 学后评价
├── research/                 # 已有分析、术语与面经映射
├── assets/course_maps/       # 30 张 PNG / SVG 目录图和机器可读目录
├── templates/                # 笔记与实验模板
└── scripts/                  # 课程介绍文案与事实卡
```

## 怎么持续记录

1. 选一门，打开它的 `courses/<course-id>/README.md`，确认官方入口与当前版本。
2. 在 `notes/` 写章节笔记；不理解的词先留问题，再查术语表与原文。
3. 在 `practice/` 留下可复现的代码、依赖与失败案例；API key 不入库。
4. 接触到一定范围后更新 `review.md`，写实际完成了什么；再调整本页状态和整体评价。

## 资料边界与来源

目录图是模块或核心章节总览；少数课程只有简介或页面级主题，其依据写在图上和课程入口中。各版本与学期分别整理，完整访问条件以官网为准。

详细研究文档保留当时的获取范围与限制。公开版收录分析、图和链接；原始网页、完整第三方教材代码、音视频、工具运行环境与个人凭证不在本仓库。文档提到的 `source/` 是原本地研究档案，不能据此认为仓库附带了课程全文。

所有课程属于各原作者和平台。转载归纳时保留课程来源与证据边界；接口、课程安排、费用与链接需在实际学习时重新核对。
