## 仓库结构

```text
Agent_Course/
├── README.md                 # 资源索引
├── OVERVIEW.md               # 整体评价与选课参考
├── courses/<course-id>/      # 单项资源信息与辅助目录
│   ├── README.md             # 官网、内容地图和研究入口
│   ├── notes/                # 可选章节笔记目录
│   ├── practice/             # 可选实践材料目录
│   └── review.md             # 课程评估空白模板
├── comparison/               # 内容主线、矩阵与证据账本
├── research/                 # 研究分析、术语与来源索引
├── assets/course_maps/       # 30 张 PNG / SVG 目录图和机器可读目录
└── templates/                # 可选笔记与实践模板
```

课程入口下的 `notes/` 和 `practice/` 目录可用于保存笔记或实践材料；`templates/` 提供可选的空白模板。

## 资料边界与来源

目录图是模块或核心章节总览；少数课程只有简介或页面级主题，其依据写在图上和课程入口中。各版本与学期分别整理，完整访问条件以官网为准。

详细研究文档保留当时的获取范围与限制。公开版收录分析、图和链接；原始网页、完整第三方教材代码、音视频、工具运行环境与个人凭证不在本仓库。文档提到的 `source/` 是原本地研究档案，不能据此认为仓库附带了课程全文。

所有课程属于各原作者和平台。转载归纳时保留课程来源与证据边界；接口、课程安排、费用与链接需在实际学习时重新核对。
