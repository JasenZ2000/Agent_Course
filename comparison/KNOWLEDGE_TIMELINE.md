# 共同知识主线

这是一条建议学习顺序，不是发展史或日历，也不是必须学完的统一考纲。每个节点的子主题可能只被部分覆盖；应用与研究分支可按目标选择。

## 概念与基础

| 编号 | 知识点 | 学会后应能解释或验证 |
|---|---|---|
| K01 | Agent、Workflow与自主程度 | 区别直接回答、固定流程与自主执行；发展史属于补充背景 |
| K02 | LLM、消息、Token与模型选择 | 理解请求和上下文；不要求先掌握全部模型训练原理 |
| K03 | 提示、指令与Prompt Patterns | 写清目标、限制与输出要求 |
| K04 | Python、异步与类型化编程基础 | 课程明确教授这些基础才计入；要求会Python不算覆盖 |

## 归并规则

- ReAct 与 loop 放在同一节点；分流、Router 与 routing 同一节点。
- 工具调用与 MCP 分开；多 Agent 与 A2A 分开；长期记忆与 checkpoint 分开。
- 旅行、客服、邮件等归入综合应用，不因业务名称不同重复增加覆盖数量。
- 框架名、教材形式、证书、价格和课时不计入内容覆盖点。框架选型本身、低代码和特殊开发方式可以作为知识点。
- 研究训练与游戏具身是分支；应用开发覆盖率默认不应被这些方向拉低。
- 粗粒度节点不是所有子主题的全覆盖；精确内容由单元格证据和后续笔记补充。
