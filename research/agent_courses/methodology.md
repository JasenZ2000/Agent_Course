# Agent 入门教材研究：方法与证据标准

研究日期：2026-10-03（北京时间）。本轮服务于用户自行撰写第一期“Agent 技术入门教材介绍”视频的资料准备。

## 分析对象与范围

核心对象为 Datawhale Hello-Agents、Hugging Face Agents Course、Microsoft AI Agents for Beginners、Anthropic Academy 与工程文档、OpenAI 官方 Agent 学习路线和文档。扩展对象为 LangChain Academy、DeepLearning.AI Agentic AI、Berkeley LLM Agents MOOC 及相关专项课程。

“课程”包括有教学顺序的正文、例子、代码、作业、测验和可获得的课件；官方产品文档、工程博客、论文、视频目录、教材分别标明类型。不能把资料集合自动称为完整课程。

## 获取的不同含义

| 标记 | 实际含义 | 可以做出的结论 |
|---|---|---|
| 完整开源工作树 | 已获取指定 commit 的课程仓库；浅克隆不含全部历史 | 该版本目录、文字、随仓代码和小文件可以本地查看；未拉取的 LFS/外链媒体另报 |
| 指定语言完整 | 取得英文、简体中文课程文字/代码；排除了其它翻译 | 可比较这两种语言；不宣称全部语言下载 |
| 公开课内文字完整 | 列表里每个公开教学页面均保存了正文 | 可分析公开书面教学；不等于逐秒观看视频、取得测验答案或完成作业 |
| 公开文档完整提取 | 官方公开网页正文按行提取保存；报告正文缺失行数 | 可以核对指定网页内容；不等于取得官方全部文档站 HTML |
| 课件/代码完整、视频未取得 | 取得课程官方公开仓库或讲义 | 可评估这些材料；课堂讲解体验仍待实际观看 |
| 目录/样例可见 | 仅取得公开教学目录、介绍和部分实例 | 只判断教学设计与已见例子；不判断隐藏课内解释质量 |
| 登录/付费/错误/重定向壳 | 没有取得目标正文 | 记录缺口及正常入口；不把 HTTP 200、长导航或搜索摘要当作课程正文 |

各 provider 的 evidence.md、source manifest、Git commit 是最终获取范围的依据。下载清单比文件数量更重要：一份大仓库可能多数是翻译和图片。

## “学习体验”的判断边界

本轮是阅读和代码静态审计。可以评估知识引入顺序、解释与例子的距离、跨章节是否复用同一个项目、术语是否先定义后使用、环境与依赖说明、代码片段是否完整、练习是否有检验方法、平台账号与 API 消费要求、中文翻译是否滞后。

不能据此宣称已经完整修课、付费实验已跑通、证书已获得、某课程真实需要固定小时数，或所有版本都兼容。官方标注的课程时长通常是视频时长，不含读代码、排错和复做项目；我们的体验描述也不代表所有初学者。

## 系统性的分析维度

1. 概念主线：LLM 调用 → 工具 → 执行循环 → 状态与上下文 → 任务分流/编排 → 检索 → 评测 → 权限与运行。
2. 解释闭环：定义 → 为什么需要 → 最小例子 → 真实应用 → 失败/反例 → 检验方法。
3. 实践闭环：明确输入、可运行代码、预期输出、可修改任务、验收标准。
4. 迁移能力：是否区分通用原理与特定框架/API；换模型或平台后还剩多少知识。
5. 工程深度：是否展示失败恢复、数据权限、写操作审批、幂等、日志、成本和部署；有标题不等于教会实现。
6. 先修匹配：是否要求 Python/TypeScript、异步、JSON、网络、数据库；零 Agent 经验不等于零编程经验。

不做缺乏学习实测依据的百分制总分。课程适合不同起点，采用有解释的相对判断。

## 与面经对应的标准

本地样本来源：[面经研究](../agent_interview_review.md)、[国内扩充](../interview_catalog_china_expanded.md)、[海外扩充](../interview_catalog_overseas_expanded.md)。重点原帖：[小红书 Agentic 全栈实习一面自述](https://www.nowcoder.com/feed/main/detail/e5e9311a623940eead6ec98c65e7f9e8?sourceSSR=subject)。

| 覆盖标记 | 标准 |
|---|---|
| 直接讲解 | 有可定位的定义、解释与例子/代码，直接回答该知识点 |
| 部分相关 | 有相邻内容，但缺少原问题中的判断、约束或实验 |
| 需要补充项目 | 给了工具或原理，学生仍需实际做实验才能回答个人设计选择 |
| 未见 | 在取得并审阅的指定范围中未见，不能推断整个品牌不存在相关教程 |
| 无法判断 | 正文受限或仅目录可见，不能当作“没有覆盖” |

面经只支持某投稿者对某次面试的自述，不能据此推断统一考纲、某厂必考或课程覆盖率。没有“所有 Agent 面试”的总体分母。

## 术语处理

保留 Agent 的多种使用口径；注明 Tool、Skill、MCP、Harness、Memory 在不同生态里的定义差异。解释“重构编排层”中的“重构”是项目动作，“编排层”是架构职责；“query”在聊天输入、检索查询和 SQL 中含义不同。把术语映射到一个输入输出明确的任务，避免只用另一串术语解释。

## 后续实测如何补证据

每课程选一个核心练习，固定操作系统、Python/Node版本、commit、模型/API版本；记录新手首次跑通时间、失败原因、修改步骤、费用和实际结果，再补“实测体验”。课程展示素材使用原链接、目录和少量必要画面；分析文字采用自己的解释。源资料快照保留原站署名与许可。

### 文字页面和实际学习体验分开表述

Anthropic Academy 页面有正文和官方课程时长，但视频没有观看或下载。OpenAI 指南以公开正文行提取保存，HTML 未取得。当前分析都基于阅读和静态代码检查：不声称操作过教学平台、跑通代码、配置权限、获得徽章、做过付费模型调用或测试线上费用。课程页写的时长是官方页面标注值，不含代码复现和排错时间。

静态代码阅读要标清三种例子：

1. **完整可执行的示范路径**：文字看起来可复制，不表示已在本地或当前 SDK 版本验证。
2. **模拟数据或合成结果**：如返回常量天气或合成 eval case，只支持解释概念。
3. **教学占位或省略实现**：如 RRF 检索融合中的排名合并空循环，必须指出缺了什么，不叫“完整代码”。

基于课程或文档作系统性评价时，沿用前面的“概念主线、解释闭环、实践闭环、迁移能力、工程深度、先修匹配”六项维度。每项判断至少给出具体页面或例子；优点和缺口同时写，避免用没有证据的“全面、系统、适合所有人”等定语。

### 术语与版本归属

Agent、Workflow、Harness、Session/Memory、Tool、Skill、MCP、Handoff 和 Guardrail 要说明在当前出处中的实现口径。比如 Anthropic Academy 的 Skill 是 procedure/package 和 `SKILL.md`，Tool 是可执行动作；OpenAI Agents SDK 的 handoff 表示转移运行控制权，Agents-as-tools 让 manager 保留控制。不同生态的术语相近，也不能视为 API 相同。标记示例对应的 SDK、endpoint 和页面抓取日期；产品文档有变化时依最新官方版本校准。

## 引用与复核原则

- 每份 provider 文档链接官方入口和代表性单课/指南，避免把本地摘要写成无源事实。
- 直接结论引用最贴近的课程或指南页面；涉及静态快照计数时引用本地 manifest，不用官网当前目录反推抓取时状态。
- 逐课概述使用独立措辞，不将课程正文或字幕误标为完整 transcript。
- “未见”只表示本次取得和阅读的范围没有看到，不推出官方全站不存在；被错误、重定向或登录壳挡住的页面单列为不可判断。
- 本地源码与 manifest 保存时间、final URL、SHA-256 之间的差异要及时修复；复核可读路径和 Markdown 链接，避免把正文来源与重复/未取得项混在一起。
