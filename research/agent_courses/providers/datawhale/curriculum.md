# Hello-Agents 课程结构与学习路径

研究基准：Datawhale 仓库固定提交 [`4b014ad47e2658af24b59f21e7bdb3f89a66205e`](https://github.com/datawhalechina/hello-agents/tree/4b014ad47e2658af24b59f21e7bdb3f89a66205e)。这里按仓库的中文主目录逐章盘点，阅读的是教材与代码文件，不包含视频实看或运行验收。课程判断和限定见 [analysis.md](analysis.md)，来源边界见 [evidence.md](evidence.md)。

## 五部分的教学安排

| 部分 | 章节 | 主要任务 | 学习者得到什么 |
|---|---|---|---|
| 一、智能体与语言模型基础 | 1–3 | 建立 Agent、环境、循环和 LLM 的基本词汇 | 能把“模型回答问题”与“系统观察、选工具、执行、再观察”区分开 |
| 二、构建 LLM Agent | 4–7 | 手写范式、使用低代码产品、比较框架、搭建自己的 Agent 基类和工具系统 | 能比较不同实现形态，并理解框架替自己封装了哪些部分 |
| 三、高级知识扩展 | 8–12 | Memory/RAG、上下文、通信协议、Agentic RL、Agent 评估 | 能识别状态、检索、交互协议、训练和评估是不同系统问题 |
| 四、综合案例 | 13–15 | 旅行、深度研究、赛博小镇 | 将 Agent 组件组合到 Web 和游戏形态，看到外部 API、存储与用户交互 |
| 五、毕业设计 | 16 | 自选项目、整理实现、测试、文档和贡献 | 以可读仓库和 PR 形式整理成果；实际选题与验收由学习者/社区承担 |

## 学习路线建议

### 想先弄懂 Agent 是什么

读 1、3 章，再读 4.2 ReAct。先能解释“输入从哪里来、工具如何选择和执行、Observation 如何反馈、任务在哪里结束”。第 2 章可当背景阅读，不需要把发展史当成动手前置条件。

### 想比较架构和实现方式

按 4 → 6 → 7 顺序读：手写环节，再观察 AutoGen/AgentScope/CAMEL/LangGraph 的框架取舍，最后看框架接口与工具系统。第 5 章低代码平台可以放在这条路线里作对比，不必同时完整搭完四个平台。

### 想做可展示的应用

先选一个项目作为主线：第 13 章适合 API/工具和多 Agent 流程；第 14 章适合长研究计划、检索和报告；第 15 章适合个体记忆、状态和交互界面。然后回看第 8–12 章中与你项目有关的记忆、上下文、协议、评估部分。

### 想准备工程面试

优先 4、6–10、12–15 章。将面试题转成一个能展示的最小实验：固定输入集、工具调用日志、失败/超时案例、权限边界、评估结果。第 11 章对应用工程面试通常是专项补充，除非岗位明确要求训练/微调。

这些路线只按书面材料的依赖关系建议阅读顺序，不是作者官方认证路径，也不表示完成其中章节就达到岗位要求。课程时间、首次配置成本与代码成功率尚无本次实测数据。
