# DeepLearning.AI：Agentic AI 分析

研究日期：2026-10-03（Asia/Shanghai）  
分析对象：Andrew Ng 主讲的 Agentic AI 在线课程之公开视频转录、课程目录线索与官方社区页面。实际视频没有播放；课程页面抓取件中有通用播放器壳，不把它们当作课程正文。详细获取边界见 [evidence.md](evidence.md)，章节地图见 [curriculum.md](curriculum.md)。

## 结论

这门课的主线是开发方法而非某一个 Agent 框架：把任务拆成可以由模型、代码或工具完成的步骤，先做工作流原型，再通过反思、外部反馈和评测逐步改进，复杂任务再考虑多 Agent 协作。转录里反复出现“先定义每步解决什么问题，再看结果是否值得增加复杂度”的工程判断。它适合用来理解 Agentic Workflow 的动机、设计模式、工具接入和评测闭环。

最具体的贯穿案例是 Research Agent。用户给一个研究主题，系统先列提纲并生成搜索词，再取回网页、写草稿、检查是否缺少研究或有不连贯之处、修订，最后输出报告。课程把一个“直接写 essay”的单次生成问题改造成多步流程；随后又用 customer support email、invoice processing、spreadsheet chart 和 marketing assets 解释哪些环节要用模型、数据库/API、代码执行或多个角色。案例使工作流概念易懂，也能看见“需要何时动态调用工具、何时开发者固定步骤”的区别。

## 讲解结构与术语完整性

公开课程目录线索把内容分为五个模块：Introduction to Agentic Workflows、Reflection Design Pattern、Tool use、Practical Tips for Building Agentic AI、Patterns for Highly Autonomous Agents。第一模块从 Agentic AI 定义、自治程度和直接生成的局限开始，讲任务分解与计划；第二模块讲模型自评及外部执行结果如何提升修订；第三模块讲函数工具、代码执行和 MCP；第四模块用端到端评估、组件评估、错误分析、成本/延迟来组织开发迭代；第五模块引入多 Agent 和通信模式。

讲义转录对“是否一定要称为 Agent”采取务实口径：Agentic 是程度而非二元标签。它同时区分程序员固定的工作流节点与模型自主选择的工具调用。工具例子从 get_current_time 延伸到网页搜索、销售数据库 SQL 查询、利息计算与代码执行。反思示例展示只让模型自评可能帮助有限，若能执行代码并把异常反馈回来，下一轮才有新的信息。MCP 例子把重复对接问题概括为应用数 M 与工具数 N 的 M×N 集成，采用客户端/服务端标准后把封装工作变为 M+N，并演示 GitHub MCP Server 取 README 和列 Pull Request。

课程在实用评测方面讲得扎实。转录里用 invoice 日期抽取、marketing 文案长度、chart rubric、论文重点覆盖展示“代码判定或模型裁判”与“是否存在逐题标准答案”的两条评测轴；Research Agent 的组件评测再单独检索质量，用专家选定的权威网页作 gold set。开发者先用约 10–20 个任务查看输出和 trace，再做错误分类、组件级评测和成本/延迟测量。这个次序把实验方法落到了可操作的数据上，而非仅给设计模式名字。

## 学习体验与适用边界

可审阅的核心材料是口语化讲解的纯文本转录和一个公开的课程目录索引。转录里步骤解释、业务场景与示意运行过程较多，适合快速理解流程；缺少同一份公开本地源码、Notebook 和结果文件，所以读者不能只靠当前归档核对视频里的完整函数、依赖、错误输出或作业验收。网页提取文件虽然返回 200，但课程视频页实际只保存到重复的播放器工具说明；我们已将相关 manifest 标为 player_shell。它不等于 31 段视频正文。

转录内容能支持对讲授概念和口头案例的分析，不能替代观看体验：图表、代码演示、讲师停顿/强调与章节切换都未核验。纯文本转录还存在语音识别错词，课程社区的讲义索引明确提醒讲义未持续维护，可能缺漏或有误，建议以更新过的视频为准。因此课程定义和例子可以作为分析线索，引用精确 API 或重述细节时应回到原视频/课程代码核验。

从已读公开材料看，它没有形成一条状态存储、恢复、人工审批、工具最小权限、幂等、数据库事务和部署容量的系统工程主线。Agentic AI 范围覆盖从固定 workflow 到自主工具使用、MCP 和多 Agent，但“Harness”并不是课程统一使用的课程术语。用它学任务拆分、反思、工具与评测比较合适；把课程定位成完整的 Agent 工程实训或已经拿到全部实验内容，则超出当前证据。

## 研究用途

可定位的课程级例子包括：Research Agent 从 outline 到 web search、draft、critique、revision；SQL/database tool 做客户订单查找；反思接入代码执行错误；MCP client/server 的 GitHub 文件与 PR 查询；组件级搜索评测。课程示例由转录复核，视频本身尚未播放，实验代码页与作业未完整取得。
