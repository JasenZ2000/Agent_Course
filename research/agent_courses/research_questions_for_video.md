# 写综述文案时可用的研究问题与证据

这是取材提纲和待验证清单，不是口播或分镜脚本。

## 值得解释的核心区别

| 研究问题 | 可以展示的证据 | 避免误讲 |
|---|---|---|
| 这些都叫课程，其实交付形式一样吗？ | 连续章节、SDK导航、大学讲座、短课项目的目录 | 官方文档≠连续课程；研究讲座≠零基础教学。 |
| 真有从头解释工具执行的吗？ | HF dummy loop与Anthropic agent loop的模型请求/执行返回 | 模型说“执行了”不能当真实执行。 |
| 中文课能否帮完全初学者？ | Datawhale前提、定义顺序、项目代码；HF中文差异 | 中文文字不自动意味着无需Python基础。 |
| 官方说明是否已经系统化？ | Anthropic 13/67/10节文字课；OpenAI track和SDK章节 | 旧Skilljar登录壳不能推成没有新课程。 |
| 可以一门课学完所有Agent岗位问题吗？ | 面经逐问映射与教材缺口 | 后端基础、项目取舍与真实规模不能靠背名词覆盖。 |
| 课程免费，动手也免费吗？ | 微软云资源要求、各课API/模型下载前提 | 免费阅读与实际运行费用分开。 |
| 我们为什么还需要官方文章？ | harness/Skills/evals等跨课程补充 | 工程经验文章可以补体系，但不必从所有论文开始。 |

## 适合直接截图或录屏的材料

- HF英文和中文欢迎页对照：LangGraph/LangChain、认证截止信息，见HF evidence中的固定提交链接。
- Anthropic lesson_index：展示有连续课程、每课主题与本地正文，而非只展示主页封面。
- 微软STUDY_GUIDE：展示先基础再按tool/RAG/workflow/production/local分流的学习路线。
- OpenAI quickstart与orchestration：展示历史老师小例子怎样扩展到tool/handoff，而非堆框架名。
- 原牛客面经与interview_alignment：展示“一个词听不懂”怎样查成“具体章节+实践缺口”。
- worked_examples中的写操作批准：用一个参数变化解释审批与执行边界。正式拍前需要亲测日志。

## 拍之前最好由你完成的亲测

至少亲自跑通一门课的一段最小代码、改一个参数、制造一个失败，再记录你的真实体验。这样视频能同时提供文献综述和个人观察。未亲测的其他教材可以明确标为“基于公开正文和代码比较”。

需要你自己决定的编辑选择：观众是否已会Python、视频长度、哪些课程做主线、是否介绍账号/费用、中文与英文材料的权重。当前材料不强迫统一排名。

## 录制前复核

课程入口、课数、注册政策、依赖、云平台和费用都可能变化。以研究日期和版本限定结论；如果只是引用归档历史版本，就不要说“今天所有内容都一样”。公开原文链接已分档案保存，可逐条核对。
