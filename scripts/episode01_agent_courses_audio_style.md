## 开头：我看得懂这些词吗？

想学Agent，现在到底有哪些课可以选？

我之前看一篇Agent面经，里面提到意图分流、编排层、操作边界，还有harness。每个词都能搜到解释，但放在一个项目里，我就不知道它们分别在说什么了。

接着去找教材，发现选择其实很多。中文教程、吴恩达的课、Hugging Face、微软、Google，还有教你做邮件助手、写代码、跑评测的项目课。

但它们教的东西不一样。有的帮你建立概念，有的带你跟着写代码，有的解决项目做出来以后的问题。

所以这期我想给大家整理一份目录。你可以根据自己现在会什么、想做什么，找几个值得打开的入口。

先说明一下：这次主要比较公开目录、课文和代码，实际跟着做的体验，我会在后面的直播和视频里继续补。

（画面：面经中的几个词→完整资源名单，标“教材 / 课程 / 项目 / 专题 / 官方参考”。）

## 先看地图

我把这些材料分成五组。

第一组，先弄懂Agent怎么工作。第二组，跟着做一个具体项目。第三组，查模型厂商自己的接口和用法。第四组，补上下文、工具协议、评测这些专题。最后一组，是大学公开课和研究方向。

你可以直接跳到需要的部分。这个顺序方便介绍，选课时还是看自己的问题。

## 第一组：先弄懂Agent怎么工作

### 1. Datawhale：Hello-Agents

先说中文教材，Datawhale的《从零开始构建智能体》，也叫Hello-Agents。

它从基础概念开始，接着带你手写几种Agent做法，再往后讲框架、记忆、检索、上下文和项目。目录比较连续，适合边读边把概念接起来。

比如模型决定查天气，这一步只是在提出一个工具请求。真正执行函数、把结果送回去，是程序做的。先把这个循环看明白，后面再看框架，很多接口就能对上了。

想先用中文理解基本流程，可以优先翻它。后面范围很广，刚开始挑基础和手写章节就行。

### 2. 吴恩达：Agentic AI

第二个，DeepLearning.AI上吴恩达主讲的Agentic AI。

这门我比较想推荐给一种人：已经听过不少名词，但还不知道项目应该怎么设计。

比如你要做一个查资料、写报告的助手。直接让模型写，可能会漏信息；那就先列提纲、再搜索、写草稿、检查、修改。步骤怎么拆，哪里用工具，结果不好该改哪一步？课程就围绕这些问题展开。

它有五个模块，讲工作流、反思、工具使用、评测和优化，以及规划与多Agent协作。

里面值得单独留意的是错误分析。最后的报告不好，可能是搜索出了问题，也可能是写作出了问题。先把这两种失败分开，你才知道应该改什么。

它在官网列为中级课。跟代码时最好有一些Python和模型调用基础；设计方法可以先看，工程实现再配其他材料。

### 3. Hugging Face：Agents Course

接着是Hugging Face的Agents Course。

前面先讲模型、工具、行动和反馈，后面会接触smolagents、LlamaIndex和LangGraph，还有应用项目和最终挑战。

这一套适合拿来比较框架。你会看到，同样都是让模型调用工具，换一套框架，代码的组织方式会变。哪些步骤一直都有，哪些是框架替你处理的？可以边学边对照。

想学基本概念，也想看看几种实现，可以选它。跟着做需要一些Python和LLM基础；中文页面可以读，课程安排也建议对一下英文目录。

### 4. Google和Kaggle：五日Agent课程

Google和Kaggle的5-Day AI Agents Intensive，也值得放进名单。

2025版按五个主题组织：Agent基础、工具和MCP、会话与记忆、质量与评测，最后是从原型走向生产。材料把阅读、讲解和代码实验放在一起。

它有一个很清楚的学习节奏：今天学一个主题，再打开对应实验，看看代码怎么写。自己学时，完全可以把一天拆成几天。

还有2026年的Vibe Coding版，目录增加了Skills、安全等内容，和我想做的开发直播也有联系。两个版本不同，我会分别给链接。

想沿着一条安排好的路线学，可以看看这组。动手前要准备Kaggle账号和相应API凭证。

### 5. Vanderbilt：Python Agent系列

如果你更想从Python实现开始，可以看Vanderbilt在Coursera上的系列课，Jules White主讲。

这里有一门从组件开始搭Agent，也有进一步讲架构的课。工具发现、函数调用、多Agent、共享记忆，都能在目录里找到。

和前面比较框架的学习方式相比，这一组更适合问“这个部件，我自己应该怎么写”。

系列里也包含提示工程内容，选的时候看具体单课。它要求基本Python能力，完整课程、作业和证书的访问范围，需要到报名页面确认。

### 6. 微软：AI Agents for Beginners

微软的AI Agents for Beginners，适合用来看看Agent项目还会涉及哪些东西。

除了工具、检索、规划和多Agent，目录还延伸到上下文、记忆、浏览器操作、部署和安全。

比如助手已经能回答问题，接下来想保存偏好、记录失败，或者接一个浏览器任务，就可以沿目录找对应材料。

课程范围比较广，也涉及微软自己的框架和Azure资源。想跟代码时，先看安装说明，把环境配置的时间也算进去。

（画面：六张卡片，分别高亮“中文基础 / 设计方法 / 框架比较 / 集中路线 / Python实现 / 工程范围”。）

## 第二组：喜欢跟着一个项目学

如果已经知道基础流程，接下来想边做边学，就看这一组项目材料。

### 7. Datawhale：Generic Agent使用指南

中文还有另一种选择，Datawhale的Generic Agent使用指南。

它围绕一个具体系统，先教你安装、使用，再看架构、工具、分层记忆和上下文压缩，最后接案例。

如果读通用概念有点抽象，可以先把这个Agent用起来，再回头看它为什么要保存这些状态、怎样处理工具和上下文。

和Hello-Agents相比，它更围绕一个项目展开。目前项目标为Beta，跟着学时记一下版本。

### 8. freeCodeCamp：Agentic AI长课

喜欢长视频跟代码，可以看freeCodeCamp频道发布、Bappy授课的Agentic AI入门课。

视频大约二十四小时，有配套代码。内容包括异步Python、Pydantic、单Agent、多Agent、RAG和LangGraph项目。

它的选择理由很直接：想看一个人怎么把代码一步步写出来，这种长课会比较顺手。

不过先翻一下章节和项目目录。基础已经会了，就找想做的项目；视频公开，接模型和云服务的部分仍可能有成本。

### 9. LangChain Academy：Introduction to LangGraph

如果你卡在“这些步骤怎么连起来”，可以看LangChain Academy的Introduction to LangGraph。

它从节点、边和状态开始，再加上状态保存、人工介入、并行、子图和长期记忆。

举个例子，Agent准备执行一个操作，你希望它先停下来，让人检查参数，批准后再继续。或者程序中途断了，希望从之前保存的状态接着做。这些问题，都能找到对应的教学入口。

面经里的编排层，可以先用这一类例子理解。课程围绕LangGraph实现，安装和Studio用法要留意版本说明。

### 10. LangChain Academy：Ambient Agents

同一个平台还有Ambient Agents with LangGraph，围绕邮件助手做项目。

课程把构建、评测、人工介入、记忆和部署串在一起。看到一封邮件进来，什么时候处理、什么时候需要人看、哪些信息要记住，就能沿同一个应用往下想。

前一门沿框架概念教，这一门沿项目教。喜欢先看到一个任务，再理解代码，可以看看这一套。

## 第三组：用到哪家的API，就查哪家的材料

项目要接模型的时候，厂商的官方材料就很有用了。具体的参数、工具格式和SDK用法，可以到这里查。

### 11. Anthropic：官方课程

Anthropic这边，可以分别看Claude Platform 101、Building with the Claude API，以及Introduction to MCP。

先了解平台，再学请求、工具、检索和工作流，需要连接外部服务时，再进MCP。

比如用户问保修什么时候到期，却没给购买日期。接着该追问，还是调用工具查记录？这类小例子，就能把工具调用和任务流程接起来。

准备使用Claude做项目的人，可以沿官方课程学；想查Skills、上下文和SDK，也有对应材料。

### 12. OpenAI：学习路线和Agents SDK

OpenAI这一组，主要是学习路线、指南和Agents SDK文档。

可以从一个小助手开始，加工具，再看任务怎样交给另一个助手，或者把另一个助手当成工具。下一步由谁继续处理，值得对着代码看清楚。

会话、人工审批和运行记录，也都有入口。比如加一个退款工具：要退哪笔订单，退多少钱，在哪里等用户确认？面经里的操作边界，就能落到具体流程上。

这组适合项目已经确定要用这个SDK时查。想连续学习基础，可以搭配前面的教材。

## 第四组：遇到具体问题，补具体专题

项目做着做着，还会碰到一些值得单独学的问题。比如上下文越来越长，或者改了流程以后，结果反而不稳定。这一组就按问题选。

### 13. Deep Agents：harness、Skills和执行环境

这组先说LangChain Academy的Introduction to Deep Agents。

最开始让我困惑的harness，在这里就有一个具体实现可以看。课程目录包括文件系统、沙箱、上下文卸载、Skills、记忆，还有任务委派和子Agent。

你可以把harness先理解成支持Agent运行的那套程序：工具怎么执行，状态怎么保存，工作文件放在哪，什么时候停下来让人介入。具体范围，还要看各个项目怎么定义。

Skills也可以先理解成组织好的一组任务说明和配套资源。到了具体框架，再看这些文件什么时候加载、怎么使用。

如果已经会做基本工具循环，想继续读Coding Agent这类系统，这一门值得打开。

### 14. Observability & Evaluations：做出来以后怎么测

再往后，Agent Observability & Evaluations是一门独立的评测专题课。

假设你改了提示词，几个例子看起来更好了。但换一批问题，它还行不行？昨天能完成的任务，今天有没有被改坏？

这时候就需要数据集、评估器、实验记录和人工反馈。课程围绕LangSmith教这些东西。

已经有一个小项目的人，可以把自己的失败案例带进去学。以后做直播，也能把“我感觉变好了”变成一组能比较的结果。

### 15. Hugging Face：MCP Course

Hugging Face的MCP Course，和前面的Agents Course是两套材料。

它从协议和架构开始，再看SDK、服务端、客户端和开发工作流。

工具函数会写以后，想让不同客户端接进来，这时候再看host、client和server，会更容易理解。课程目录里还有Gradio、Continue和PR相关项目。

MCP解决的是连接和通信。工具接上以后，什么操作允许执行、什么时候需要批准，还得由你的应用安排。

### 16. NVIDIA：RAG与Agent应用课程

想专门做文档助手，可以看看NVIDIA的Building RAG Agents with LLMs。

RAG是检索增强生成。先从资料里找相关内容，再让模型据此组织回答；实际效果还要检查检索和生成各自有没有出错。

公开目录里有长文处理、向量检索、对话状态、前端连接和评测。可以沿着一份论文集，理解从找到资料到组织回答的过程。

NVIDIA另外还有Building Agentic AI Applications with LLMs。这个入口可以先收藏，我们目前取得的详细目录较少，先不做学习体验判断。

报名时要分清自学版和讲师版，实际环境、费用也分别看。

### 17. IBM：Agentic AI in Practice

IBM的Agentic AI in Practice是一条教程和课程组成的学习路径。

目录里能看到CrewAI、LangChain、LangGraph，以及客服、多Agent和Agentic RAG等应用。

它适合拿来找“这个框架能做哪类任务”的具体例子。想学某个项目，就再打开对应教程，看代码和运行要求。

### 18. DeepLearning.AI：项目短课

DeepLearning.AI除了吴恩达那门主线课，还有一些合作讲师的项目短课。

AI Agents in LangGraph，讲搜索、状态和人工介入，最后做研究写作助手。

Multi AI Agent Systems with crewAI，拿文章写作、客服和活动策划等任务，解释多个Agent怎么分工。

Building Coding Agents with Tool Execution，则更接近开发：写代码、操作文件、在沙箱里运行，拿到报错后继续修改。

想先挑一个能动手的方向，可以从这三门里找。讲师和具体项目，我会放在简介表里。

## 第五组：想继续看论文和研究

最后，如果你已经开始读论文，想看看Agent研究有哪些方向，可以再看大学公开课。

### 19. Berkeley：Agent公开课

Berkeley的LLM Agents MOOC和后续Agentic AI讲座，更适合用来扩展技术地图。

推理、检索、编程Agent、计算机操作、评测、安全，还有机器人方向，都能找到对应主题。

如果做项目时开始好奇，编程Agent到底怎么评测，就可以挑相关一讲，再跟着找论文和实现。它适合带着问题看。

### 20. CMU：AI Agents

CMU的11-768 AI Agents，是2026年秋季的研究生课程。

目录里有工具、规划、记忆、训练、安全和人机交互，作业还涉及Harness、评测和Agent训练。

如果已经有机器学习和语言模型基础，想继续进到研究层面，可以关注它。当前学期还在进行，公开材料也要按具体链接看，别当成已经完整开放的自学课程。

## 结尾：从目录里选一个入口

这些材料，大概就有个位置了。

想先用中文弄明白基本流程，可以翻Hello-Agents；想先用一个具体系统，再读架构，可以看Generic Agent。

会一些Python，想弄清任务怎么拆、结果怎么改，可以看吴恩达。想比较框架，可以看Hugging Face。喜欢安排好的阅读和实验，可以看看Google和Kaggle。

想跟着写代码，可以比较Vanderbilt和freeCodeCamp。项目开始涉及状态、暂停、恢复，就找LangGraph；想继续看Skills、文件系统和子Agent，再看Deep Agents。

已经做出了小项目，评测课就能派上用场。至于官方材料、MCP和研究讲座，遇到对应问题，再去翻。

我接下来想先从一个能查资料的小助手开始，把工具调用、中间记录和失败情况都留下来。直播时边读边做，下播以后，再把值得讲的地方整理成视频。

今天这份目录和课程链接，我会放在简介里。你也可以说说自己现在最想做什么，我后面选项目时可以参考。
